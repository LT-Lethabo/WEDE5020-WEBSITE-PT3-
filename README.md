## Project Overview

This is a K9 website that encourages people to train their dogs for protection with the company. The company also offers resources and dogs for sale. The website is made for anyone interested in dog protection services, whether individuals, companies or other organisations.

This repository contains the refactored frontend codebase. The project has been optimised for clean structural integrity, standards-compliant HTML5/CSS3 rendering and cross-device responsiveness.

## Website Goals and Objectives

- Inform clients and communities about the specific roles working dogs play in security and protection.

## Key Features and Functionality

- Responsive design for mobile and desktop
- Interactive contact form
- Dynamic product gallery

## 🚀 Deployment & Integrity Audits

1. Ensure your folder is named `Images_/` (case-sensitive), or update file references to lowercase to suit your host. Linux servers enforce strict capitalisation.
2. The global stylesheet must reside exactly at `css_/style.css` so the relative paths in all page headers resolve.

## Changelog

### Added
- **CSS Reset:** Universal reset for margin, padding and `box-sizing`.
- **Grid Layout:** Added `.container` class with a 3-column CSS Grid.
- **Responsive Images:** Added `.responsive-image` helper class.
- **Base Styles:** Added default overrides for `li` and `a` tags.

### Changed
- **Navigation:** Updated nav layout to Flexbox with custom hover states.
- **Header & Typography:** Applied font sizing, families and colours to `header`, `h1` and `h2`.
- **Responsive Breakpoints:** Added media queries for 768px and 480px viewports to adapt layouts for tablet and mobile devices.

### Fixed
- **Colour Definition:** Flagged invalid syntax `yellow(3, 61, 138)` on the header background for correction to standard `rgb(3, 61, 138)`.
